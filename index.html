ANEXO II - MEMORIA TÉCNICA
MEMORIA DE ESPACIOS Y EQUIPAMIENTO

1. DESCRIPCIÓN DEL ESPACIO DOCENTE (AULA TÉCNICA 04)

El curso se impartirá en el Aula 04, que cumple con los parámetros normativos:

  • Superficie útil: 65 m² (Ratio 2,1 m²/alumno para 30 puestos).
  • Instalaciones: Climatización reforzada (carga térmica GPU) y red eléctrica sectorizada con SAI.
  • Conectividad: Red cableada CAT-6A Gigabit y WiFi 6.

2. INVENTARIO HARDWARE (BIG DATA & AI)

COMPONENTE ESPECIFICACIÓN TÉCNICA
CPU AMD Ryzen 7 5800X (8 núcleos) @ 3.8GHz.
RAM 32 GB DDR4 3200MHz (Virtualización Hadoop).
GPU NVIDIA RTX 4060 Ti 16GB (Soporte CUDA 8.9).
Disco 1 TB NVMe SSD M.2 (>3500 MB/s).

3. SOFTWARE

Dual Boot (Windows 11/Ubuntu 22.04), Anaconda, PyTorch, Docker, Apache Spark, AWS Academy.

4. MOBILIARIO Y ERGONOMÍA (Punto Séptimo)

Se acredita la idoneidad del mobiliario para jornadas intensivas de programación:

  • Mesas Técnicas: 140x80cm con canalización de cableado oculta, permitiendo espacio para torre, doble monitor y escritura.
  • Sillería: Sillas ergonómicas homologadas con regulación lumbar y altura, aptas para uso intensivo (8h).
  • Medios Audiovisuales: Panel Interactivo 75" 4K y Pizarra blanca vitrificada magnética de 3m.
