Dossier de Autorización: IA y Big Data

Guía Maestra para la tramitación ante la Delegación de Desarrollo Educativo

🗺️ 1. El Proceso de Inspección (Detalle Técnico)

Objetivo: Este ciclo es de "Alta Especialización". Las visitas no son rutinarias; se audita la capacidad real del centro para ejecutar modelos de Machine Learning.
A. Visita Técnica APAE (Infraestructuras) Filtro 1

El técnico de la Agencia Pública Andaluza de Educación verificará:

  • 📏
    Dimensiones del Aula:
    Normativa: 1.5 m² útiles por alumno. Para un grupo de 20 alumnos, se requieren mínimo 30 m² libres de obstáculos. Se medirán pasillos de evacuación (mínimo 1-1.20m).
  • ⚡
    Potencia Eléctrica y Red:
    El centro debe certificar que la instalación soporta la carga simultánea de 20-30 Workstations con GPUs dedicadas (aprox. 500W-700W por equipo). Se revisarán tomas de tierra y cuadros eléctricos sectorizados.
  • ❄️
    Climatización:
    Debido al calor generado por equipos de computación intensiva, se recomienda demostrar capacidad de refrigeración adecuada en el aula técnica.
B. Auditoría Académica (Inspección) Crítico

La Inspectora de Educación revisará la documentación pedagógica y laboral:

  • 🧑‍🏫
    Cualificación del Profesorado:
    Se cotejarán los títulos originales (Grado/Ingeniería + Máster Profesorado). Vital: Revisión de los CVs para encontrar la "Formación o experiencia específica en IA" exigida.
  • 📚
    Programación Didáctica:
    Deben presentarse las guías docentes de los módulos con bibliografía actualizada (no libros de 2010) y uso de herramientas modernas (Python, R, TensorFlow).

🖥️ 3. Recursos Técnicos (Detalle Ampliado)

No basta con "ordenadores". La inspección valorará si se dispone del ecosistema necesario.

Hardware (Estaciones de Trabajo)

Componente Especificación Recomendada (Evidencia)
Procesador (CPU) Intel Core i7/i9 (12ª Gen+) o AMD Ryzen 7/9 (5000+). Mínimo 8 núcleos físicos para virtualización.
Memoria RAM 32 GB Recomendado (16 GB es el mínimo absoluto, pero riesgoso para Big Data).
GPU (IA) NVIDIA RTX 3060/4060 (12GB VRAM recomendados). Necesario soporte de núcleos CUDA para Deep Learning.
Almacenamiento SSD NVMe 1TB. Velocidad de lectura crítica para carga de Datasets masivos.

Software y Entornos (A incluir en inventario)

Categoría Herramientas a listar en la memoria
Big Data Apache Hadoop, Apache Spark, MongoDB, Docker (Contenedores).
IA / ML Python (Anaconda), TensorFlow, Keras, PyTorch, Scikit-learn.
Cloud Acceso a AWS Academy, Azure for Students o Google Cloud (Créditos educativos).
